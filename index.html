WHAT EACH MODE DOES
Original  Stream copy (-c copy) — no re-encode. Moov atom → front. Strips metadata fingerprints. Fastest, zero quality change.
Enhanced  Same as Original + FFmpeg sharpening filter (unsharp mask), contrast boost, saturation lift. Re-encodes video — slower but visually crisper on TikTok's compressed output.
H.265  Re-encodes to HEVC (H.265). Same resolution, same perceived quality — typically 30–50% smaller file size. Good for storage and upload speed. Audio stays untouched.
NOTE  TikTok's compression is server-side and not fully public. A clean high-bitrate source is the strongest input. No tool guarantees skip 100% of the time.
